# Visual Inspector

Autocontrol visual de producto: compara el patrón gráfico aprobado por el cliente (PDF) con las
dos muestras escaneadas de cada control de impresión y resalta las diferencias.

Aplicación web interna de Witte y Solà (C# · .NET 10 · Blazor · MariaDB · Docker). Toda la
documentación está en la carpeta [doc/](doc/):

- [Descripción](doc/descripcion.md) · [Arquitectura](doc/arquitectura.md) ·

  [Cambios](doc/cambios.md)
- Notas del Máster de IA: [doc/master/](doc/master/)
