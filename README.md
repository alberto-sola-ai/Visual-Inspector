# Visual Inspector

Autocontrol visual de producto: compara el patrón gráfico aprobado por el cliente (PDF) con las
dos muestras escaneadas de cada control de impresión y resalta las diferencias. Toma la orden de la
planificación de producción (Google Sheets) y busca el patrón en la carpeta de patrones por su
especialidad.

Aplicación web interna de Witte y Solà (C# · .NET 10 · Blazor · MariaDB · Docker). Toda la
documentación está en la carpeta [doc/](doc/):
